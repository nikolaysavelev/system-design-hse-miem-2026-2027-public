# Занятие 2. Инструментарий агентов: модели, провайдеры, skills, MCP, харнессы

Политика курса по ИИ и таблица доступных агентов: `docs/ai-agents.md`. Эта страница повторяет то, что показывалось на занятии 2, в порядке показа, и дает ссылки, чтобы собрать рабочее место самостоятельно. Курс не требует платного агента: любой вариант из раздела 4 достаточен для всех домашних работ, а аналитический режим ДЗ агента не требует вовсе.

## 1. Из чего состоит агент

Агент для разработки это четыре слоя, и каждый выбирается отдельно.

Модель: то, что думает. Открытые модели лежат на Hugging Face, закрытые у вендоров. Провайдер инференса: где модель выполняется (у вендора, у агрегатора вроде OpenRouter, у провайдера на Hugging Face, локально через Ollama). Харнесс: программа, которая превращает модель в агента: читает файлы, запускает команды, ведет цикл "план, действие, проверка" (Claude Code, pi.dev, OpenCode, GigaCode, Cursor). Контекст и инструменты: что агент знает и что умеет: файлы `AGENTS.md` или `CLAUDE.md`, skills, MCP-серверы.

Качество результата агента равно качеству контекста. Это тезис занятия 1, и инструменты ниже это способы задать контекст.

## 2. Модели и провайдеры

Hugging Face, каталог моделей: `huggingface.co/models`. Фильтры по задаче (text-generation), лицензии, размеру. Карточка модели содержит число параметров, требования к памяти и лицензию; для ноутбука с 16 ГБ подходят модели до 14–20 млрд параметров в квантованном виде.

Hugging Face Inference Providers: `huggingface.co/docs/inference-providers`. Одна точка входа к нескольким провайдерам, которые выполняют открытые модели; удобно, чтобы попробовать модель без локального запуска.

OpenRouter: `openrouter.ai`. Агрегатор моделей с единым API в формате OpenAI. Ключ выпускается в разделе Keys; у части моделей есть бесплатный тариф с суточным лимитом (суффикс `:free` в имени модели). Это самый короткий путь подключить терминальный агент к сильной модели. Пополнение из РФ только через посредников, бесплатных моделей для домашних работ хватает.

Ollama: локальный запуск, `ollama pull qwen2.5-coder:14b`. Медленно на ноутбуке, зато без сети и без ключей.

## 3. Контекст и инструменты

AGENTS.md и CLAUDE.md: файл в корне репозитория, который агент читает перед задачей. В `soldout/AGENTS.md` записаны правила проекта; `CLAUDE.md` это то же самое для Claude Code. На занятии сравнивались результаты агента с таким файлом и без него.

Agent Skills: папки с инструкциями для конкретного типа задач, которые агент подключает по необходимости. Каталог и лидерборд: `skills.sh`. Формат открытый, один и тот же skill работает в разных харнессах.

MCP, Model Context Protocol: стандарт, по которому агент получает инструменты: базу данных, трейсы, Grafana, браузер, Figma. В курсе используются Postgres MCP (занятие 3), Tempo MCP и Grafana MCP (занятие 4), Kubernetes MCP (занятие 7). Каталоги серверов: официальный реестр `github.com/modelcontextprotocol/servers` и каталоги у вендоров харнессов. Подключение описывается одним JSON-файлом (`.mcp.json` в корне `soldout/`), который читают Claude Code, Cursor, VS Code Copilot, pi.dev.

Правило курса для MCP с доступом к инфраструктуре: только чтение. Postgres MCP в restricted-режиме, kubeconfig агента без прав на запись. Причина обсуждалась на занятии 1: ошибка агента должна оставаться в diff, а не в базе или кластере.

## 4. Харнессы

Подробная таблица с доступностью из РФ в `docs/ai-agents.md`, раздел 3. Коротко, что показывалось.

pi.dev: минималистичный терминальный агент с открытым кодом; читает `AGENTS.md`, поддерживает skills и MCP, модель любая через OpenRouter. Ближе всего к тому, что видно на занятиях с Claude Code. Установка и подключение OpenRouter: `docs/ai-agents.md`, раздел 4.

GigaCode: агентный режим, бесплатно при регистрации на GitVerse, без VPN. Самый простой путь, если не хочется возиться с ключами.

OpenCode, Kilo Code, Cline, Roo Code: открытые агенты, модель через OpenRouter или локально.

Claude Code: то, что использует преподаватель. Платно и официально недоступно из РФ; все, что показывается с его помощью, воспроизводимо любым агентом выше, материалы курса используют вендор-нейтральный `AGENTS.md`.

Расширения VS Code, которые помогают независимо от харнесса: клиент MCP в самой VS Code (Copilot Chat умеет подключать серверы из каталога), просмотрщик Mermaid для диаграмм из `lessons/*/diagrams`, Go, Docker.

## 5. Минимальная сборка для домашних работ

1. Харнесс: GigaCode или pi.dev.
2. Модель: для pi.dev ключ OpenRouter и бесплатная модель; для GigaCode встроенная.
3. Контекст: форк репозитория курса, в нем уже есть `soldout/AGENTS.md`, `docs/constitution.md`, `docs/adr/`.
4. Проверки: `make lint-all && make test && make invariants` после каждой задачи агента. Зеленый результат это минимальное условие, не доказательство правильности.
5. В отчете раздел "Как использовался ИИ": инструмент, что делал агент, где ошибся, как вы это заметили.
