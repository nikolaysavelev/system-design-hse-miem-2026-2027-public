# AGENTS.md — инструкции для ИИ-агента в репозитории `<название>`

Прежде чем менять код, прочитай: `docs/constitution.md`, `spec/<система>.md`, актуальные ADR в `docs/adr/`, контракт `api/openapi.yaml`.

## Где что лежит

- `cmd/…` — точки входа и сборка зависимостей.
- `internal/<module>/{api,domain,app,adapters}` — модули; публично только `api`.
- `internal/platform/` — техническая платформа.
- `migrations/`, `seed/`, `k6/`, `tools/` — схема, данные, нагрузка, проверки.
- `.go-arch-lint.yml` — архитектурные правила; `Makefile` — все команды.

## Команды

```
make up          поднять стенд
make test        тесты
make lint-arch   архитектурный линтер
make invariants  инвариант-чекер
```

## Правила работы

1. **План до кода.** Для задач > 3 файлов сначала список файлов и тестов, потом реализация.
2. **Границы модулей.** Только через `api`; нужны чужие данные — метод в `api` владельца.
3. **Миграции.** Только новым файлом; существующие не трогать.
4. **Тесты обязательны** для каждой новой доменной и конкурентной операции.
5. **Идемпотентность и таймауты** по умолчанию (см. constitution).
6. **Готово = зелёные** `make lint-arch`, `make test`, `make invariants`. Приведи вывод.
7. **Не трогай без просьбы**: constitution, ADR, OpenAPI, k6, compose.
